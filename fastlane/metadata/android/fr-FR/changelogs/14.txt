La restauration d'une sauvegarde ne ferme plus l'application : elle se rafraîchit sur place et affiche immédiatement les données restaurées. Bivouac vise aussi désormais Android 17, la version la plus récente, pour que l'application continue de se comporter comme prévu sur les appareils les plus récents. Les versions publiées sont signées par le développeur, ce qui permet de vérifier qu'un binaire publié correspond bien au code source.
